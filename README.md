# Japan Judicial Knowledge Audio Series

**Author:** Cecep Mustafa · Indonesian Judicial College (IJC) · ORCID [0000-0003-0037-497X](https://orcid.org/0000-0003-0037-497X)

Twelve episodes comparing Japanese judicial practice (civil conciliation, case management, legal aid, judicial training, court IT, judicial AI governance, court performance) with Indonesian court reform. Each episode has a written text and an MP3 recording by Cecep Mustafa.
